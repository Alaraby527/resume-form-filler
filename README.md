# 网申表单快速填充助手

一键识别网申表单并自动填充预设信息，专为校招投递打造。支持多套配置、自定义字段映射、预览确认，省去每次投递重复填表的烦恼。

## 功能特性

- **一键填充**：打开网申页面，点击插件图标即可自动识别并填充表单
- **多套配置**：可保存多套个人信息（如不同岗位/公司用不同简历），随时切换
- **预览确认**：填充前先展示匹配结果，确认无误后再填入，避免误填
- **通用适配**：通过关键词智能匹配，适配各种招聘网站的网申系统
- **自定义映射**：遇到特殊字段名时可添加别名，越用越准
- **全字段支持**：文本框、下拉框、单选/多选、大段文本均可填充
- **未填提示**：列出未能自动填充的字段，提醒手动补全
- **高亮反馈**：已填充字段绿色高亮，一目了然

## 安装方法

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 回车
2. 打开右上角的 **「开发者模式」** 开关
3. 点击左上角 **「加载已解压的扩展程序」**
4. 选择本插件的文件夹（`resume-form-filler` 文件夹）
5. 安装完成，浏览器右上角会出现插件图标

> 提示：Edge 浏览器同样支持，进入 `edge://extensions/` 操作步骤相同。

## 使用流程

### 第一步：填写个人信息

1. 点击浏览器右上角的插件图标，打开弹窗
2. 在弹窗中按分类填写你的个人信息（基本信息、教育经历、实习与项目经历等）
3. 点击 **「保存配置」**

### 第二步：填充网申表单

1. 打开你要投递的网申表单页面
2. 点击插件图标
3. 点击 **「扫描并填充」**
4. 弹窗会切换到预览界面，列出匹配到的字段及将填入的值
5. 检查无误后，点击 **「确认填充」**
6. 已填充字段会绿色高亮，未识别字段会列出提示你手动补全

### 多步骤表单

对于分页的网申表单（如：基本信息 → 教育经历 → 实习经历）：
- 每填完一页，手动点击「下一步」
- 再次点击插件图标 →「扫描并填充」即可填充新一页

## 多套配置管理

- **新建配置**：点击弹窗顶部的 **「＋」** 按钮，输入名称即可创建新配置（如"技术岗""产品岗"）
- **切换配置**：顶部下拉框选择不同配置
- **重命名**：点击 **「✎」** 按钮
- **删除配置**：点击 **「✕」** 按钮（至少保留一个）

## 字段映射设置

当某个网申系统的字段名称比较特殊、插件无法识别时，可以添加自定义别名：

1. 点击弹窗底部的 **「⚙ 字段映射设置」**，打开设置页
2. 找到对应字段，在「自定义别名」输入框中输入该字段在表单中的其他叫法
3. 多个别名用逗号分隔
4. 点击 **「保存设置」**

**示例**：如果某网申把"手机号"叫做"移动电话"，在「手机号」字段的自定义别名中输入"移动电话"并保存，下次即可正确识别。

## 常见问题

**Q：点击"扫描并填充"提示"无法连接到页面"？**
A：请刷新网申页面后重试。内容脚本需要页面加载完成后才能工作。

**Q：某些字段没有被识别？**
A：在「字段映射设置」中为该字段添加自定义别名即可。

**Q：下拉框/单选项没有正确选中？**
A：预览确认界面可手动修改值，确认填充时会尝试匹配最接近的选项。

**Q：数据存储在哪里？安全吗？**
A：所有数据存储在浏览器的本地存储（chrome.storage.local）中，不会上传到任何服务器，仅在本机本浏览器可用。

**Q：文件上传（简历附件）能自动填吗？**
A：出于浏览器安全限制，文件上传无法自动填充，需手动上传。
